Let's Begin

Every algebra step you've ever done has a name. Now you'll write it down.

When you solve 2x + 6 = 14 and subtract 6 from both sides, you're not just moving numbers around — you're using a specific, named rule that keeps both sides equal. Today we name every rule, because starting next week, every proof step needs one written right next to it.

By the end of today, you will be able to:

  • 1Name the property of equality used in an algebra step
  • 2Solve an equation while justifying every step
  • 3Read a two-column statement/reason format

The Rulebook

Properties of Equality

PropertyWhat it lets you do
Addition PropertyAdd the same number to both sides
Subtraction PropertySubtract the same number from both sides
Multiplication PropertyMultiply both sides by the same number
Division PropertyDivide both sides by the same nonzero number
Distributive Propertya(b + c) = ab + ac
Substitution PropertyReplace a value with something equal to it

💡 None of this is new math — you've been using every one of these since early algebra. What's new is writing down which one you used, every time.

A New Habit

Statement & Reason — side by side

Starting today, every algebra step gets written as two columns: what you did (Statement) and why you were allowed to do it (Reason). This exact format is what a full two-column proof looks like — you're already halfway there.

StatementReason
2x + 6 = 14Given
2x = 8Subtraction Property of Equality
x = 4Division Property of Equality

Two More You'll Need

Properties that don't involve solving

1
Reflexive Property
Anything equals itself. AB = AB. This looks too obvious to matter — but proofs use it constantly to justify a shared side or angle.
2
Symmetric Property
If a = b, then b = a. Order doesn't matter for equality — you can flip a statement around.
3
Transitive Property
If a = b and b = c, then a = c. (This should feel familiar — it's the Law of Syllogism from last week, applied to equality.)

Why This Matters

This is literally the format every proof will use

The statement/reason table you just practiced with algebra is not a warm-up exercise for proofs — it is a proof, just about numbers instead of shapes. Starting next week, the "statements" will be about segments and angles instead of x, and the "reasons" will include postulates and definitions alongside these same properties.

Real world: auditors and accountants justify every number on a financial statement the exact same way — every figure has to trace back to a specific, named rule or source. That discipline of "show your reason, not just your answer" is the same one this lesson is building.
