Let's Begin

Classifying quadrilaterals with nothing but coordinates

Just like we did with triangles in Lesson 4.7, we close Chapter 6 by using the Distance and Slope Formulas to classify a quadrilateral precisely — from plain quadrilateral all the way down to square — using only the (x, y) coordinates of its vertices.

By the end of today, you will be able to:

  • 1Use slope to test whether sides of a quadrilateral are parallel or perpendicular
  • 2Use distance to test whether sides or diagonals are congruent
  • 3Combine both tools to fully classify a quadrilateral on the coordinate plane

Recall

Your two key tools, back again

Distance Formula
d = √[(x₂ − x₁)² + (y₂ − y₁)²]
Slope Formula
m = (y₂ − y₁) / (x₂ − x₁)

Same slopes = parallel sides. Slopes that are negative reciprocals = perpendicular sides. Equal distances = congruent sides or diagonals. Every quadrilateral classification in this chapter reduces to checking these two things at the right spots.

Worked Example

Testing for a parallelogram

Problem: Quadrilateral has vertices A(0,0), B(4,0), C(6,3), D(2,3). Is ABCD a parallelogram?

1
Slope of AB
(0−0)/(4−0) = 0
2
Slope of DC
(3−3)/(6−2) = 0 — matches AB, so AB ∥ DC
3
Slope of AD and BC
Both equal 3/2 — so AD ∥ BC too. Both pairs of opposite sides are parallel → ABCD is a parallelogram.

Worked Example

Upgrading to a rectangle

Problem: Using the same ABCD from the last slide, is it a rectangle?

1
Check for right angles via slope
Slope of AB = 0 (horizontal). Slope of AD = 3/2. A horizontal side and a slanted side are perpendicular only if the second slope is undefined — 3/2 is not undefined, so ∠A is NOT a right angle.
2
Conclusion
ABCD is a parallelogram, but not a rectangle — consecutive sides are not perpendicular.

Worked Example

Testing for a rhombus using distance

Problem: Quadrilateral has vertices P(0,0), Q(4,0), R(5,3), S(1,3). All four sides: PQ = 4, QR = √10, RS = 4, SP = √10. Is PQRS a rhombus?

1
Compare all four side lengths
PQ = 4 and RS = 4, but QR = √10 ≠ 4
2
Conclusion
Not all four sides are congruent, so PQRS is NOT a rhombus (it's still a parallelogram, since opposite sides do match: PQ = RS and QR = SP).

Why This Matters

The same method that closed Chapter 4, one level up

Land surveyors classifying property boundaries, and CAD software auto-detecting shapes in a floor plan, use exactly this coordinate-based classification pipeline — check parallelism first, then check side lengths, then narrow down to the most specific correct shape name.

Real world: GPS-based land parcel mapping relies on this same distance-and-slope logic to auto-flag whether a plotted boundary is a true rectangle (for zoning purposes) or an irregular quadrilateral.
