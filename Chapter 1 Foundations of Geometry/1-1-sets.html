Let's Begin

Everything you own already belongs to a group.

Think about your backpack. Inside it: your phone, a couple of pencils, maybe a notebook. Every one of those things belongs to the same group — “stuff in my backpack.”

In math, we have a name for a group like that. It's called a set. Sets are the very first building block of geometry — every shape you'll learn this year is really just a set of points. So today we start there.

By the end of today, you will be able to:

  • 1Say what a set is and name what's inside it
  • 2Write a set using math symbols
  • 3Tell whether a set is empty, has one thing, or has many things

Vocabulary · Part 1

Three words to know before we start

Set

A set is a group of things that are collected together. Each thing only needs to make sense as part of the group — nothing else.

💡Think of it as: a backpack, a playlist, a grocery list — any group you could name.
Element (Member)

An element (or member) is one single thing inside a set. A set can have zero, one, or many elements.

💡Think of it as: one pencil is an element of “stuff in my backpack.”
∈ symbol

The symbol ∈ means “is an element of” or “belongs to.”

💡Example: pencil ∈ {stuff in my backpack} — reads as “pencil belongs to the set of stuff in my backpack.”
∉ symbol

The symbol ∉ means “is NOT an element of.” Same symbol as before, just with a slash through it.

💡Example: car ∉ {stuff in my backpack} — a car does not belong in that set!

Vocabulary · Part 2

Three more words — about the size of a set

Empty Set

A set with nothing inside it. Written as ∅ or as empty braces { }.

💡Think of it as: a backpack you haven't packed yet. It's still a set — it's just empty.
Subset (⊆)

A subset is a smaller set made only from things already in a bigger set. Every element of the subset must also be in the bigger set.

💡Example: {pencils} is a subset of {stuff in my backpack} — every pencil is backpack stuff, but not every backpack item is a pencil.
Finite vs. Infinite

Finite means you could count every element and eventually stop — there's a last one. Infinite means the set keeps going forever; there is no last element.

💡Hold onto this one: next week you'll learn that a line is an infinite set of points — it never stops. That idea starts right here.

How It Works

Writing a set with symbols

We write a set by listing its elements inside curly braces { }, separated by commas. We usually give the whole set a capital letter name.

A = { △, □, ● }

“Set A contains a triangle, a square, and a circle.”

Two rules that surprise people at first:

  • Order doesn't matter. {△, □, ●} is the exact same set as {●, △, □}.
  • Repeats don't matter. If you accidentally list something twice, it still only counts once. {△, △, □} is the same set as {△, □}.

💭 Quick check with yourself: is B = {□, △} the same set as A = {△, □, ●}? — No! B is missing the circle. Same rules, but different elements means a different set.

Seeing a Set

Venn diagrams — drawing a set as a picture

A Venn diagram draws a set as a circle (or oval). Everything written inside the circle is an element of that set. Anything outside the circle is not in the set.

S = {△, □, ●}. The star is outside the circle, so ★ ∉ S.

Venn diagrams are named after John Venn, a mathematician who started drawing sets this way in the 1880s — and it's still the way we draw them today.

Worked Example

Let's do one together, step by step

Problem: On the front desk of the classroom sits a triangle magnet, a square sticky note, a circle stamp, and a red pen. Let D be the set of everything on that desk.

1
List the elements
triangle magnet, square sticky note, circle stamp, red pen — that's everything sitting on the desk.
2
Write the set
D = {triangle magnet, square sticky note, circle stamp, red pen}
3
Ask: is “circle stamp” an element of D?
Yes — it's sitting right there on the desk. So: circle stamp ∈ D.
4
Ask: is “stapler” an element of D?
No — nothing was said about a stapler being on the desk. So: stapler ∉ D.

Why This Matters

Sets are the reason geometry works at all

Here's the big idea we're building toward: every shape you study this year is really a set of points.

Next week, in Lesson 1.2, we'll meet the three ideas everything in geometry is built from — point, line, and plane. Every one of them is defined using exactly what you learned today: sets, elements, and infinity.

Sets aren't just a geometry thing

  • A sports team roster is a set of players.
  • A playlist is a set of songs.
  • Your class schedule is a set of classes.

Anywhere you can name a group and say what does or doesn't belong to it, you're already thinking in sets.
