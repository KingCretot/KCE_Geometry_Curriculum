# KCE Geometry Curriculum

Original KCE-authored tutoring curriculum for high school Geometry, built to
accompany BJU Press *Geometry*, Fifth Edition (© 2025, ISBN 978-1-64626-500-8).
Content follows the book's own scope, sequence, and terminology, but is
independently written by KingCretot Experience — not a reproduction of the
textbook.

Designed for 1:1 tutoring sessions, one lesson per 60-minute weekly session.
Built to be reusable across students and reused at whatever section a
student's class is currently on — not tied to any one student's pace.

## File naming

Files are named to match BJU Press's own section numbers (`1-1`, `1-2`, etc.),
**not** sequential lesson order. This means a tutor or future student can jump
straight to whatever section their class is on that week, without needing to
know how many KCE lessons come before it.

Algebra 1 lessons: Slide 1 collects the student's name; guided-practice and
quiz questions give two attempts (one on two-choice questions) before the
answer is revealed; answer order is shuffled on each load; and the final quiz
